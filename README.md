# E-Commerce & Retail Business Intelligence

## Project Overview
An end-to-end Business Intelligence project built using SQL Server and Power BI to analyze e-commerce sales, profitability, product performance, customer activity, and returns.

## Tools & Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Microsoft Power BI
- DAX
- SQL

## Project Objectives
- Analyze overall sales and revenue performance.
- Evaluate product and category performance.
- Monitor profitability and profit margins.
- Analyze customer and order activity.
- Understand return trends and return statuses.
- Build interactive dashboards for business reporting.

## Database Overview
The project uses a SQL Server database named `EcommerceRetailDB`.

**Main tables:**
- Customers
- Orders
- OrderDetails
- Payments
- Products
- Returns

**SQL Views:**
- vw_CategoryPerformance
- vw_CustomerPerformance
- vw_MonthlySales
- vw_OrderLineDetails
- vw_ProductPerformance

## Power BI Dashboard

The report contains three interactive pages:

### 1. Executive Overview
Provides a high-level view of business performance through key performance indicators.

### 2. Sales & Product Analysis
Analyzes revenue, profit, quantity sold, and product/category performance.

### 3. Customer & Returns Analysis
Provides customer activity and return-status analysis.

## Key Metrics
- Total Revenue
- Total Profit
- Total Orders
- Total Quantity Sold
- Average Order Value
- Profit Margin %
- Revenue Growth %
- Return Rate %

## Technical Implementation
- Created SQL queries and views for business analysis.
- Connected SQL Server data to Power BI.
- Developed calculated measures using DAX.
- Implemented date slicers and page navigation.
- Validated key Power BI metrics against SQL query results.

## Project Validation
Key financial and return-related calculations were cross-checked against SQL query results to ensure consistency.

## Business Value
This project demonstrates how SQL and Power BI can be used together to transform raw e-commerce data into interactive business insights that support data-driven decisions.
